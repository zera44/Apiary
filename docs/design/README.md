# Vulyk 0.3.15: увесь візуал для редизайну

Знято 16.10.2026 з телефона realme RMX3867 (1080×2400, 480 dpi), шрифт «Звичайний», темна тема.

- `index.html` — галерея всього нижче. Відкривайте з цієї папки (подвійний клік у провіднику або `python -m http.server`).
- `screens/` — 126 знімків у повній роздільності PNG, розкладені по розділах:
  `01_home`, `02_qr`, `03_map`, `04_hive_panel`, `05_apiaries`, `06_stock`, `07_finance`, `08_history`, `09_settings`, `10_lessons`, `11_landscape`.
- `assets/icons/` — 30 SVG-іконок застосунку (`objects`, `obstacles`, `ui`), реєстр `icons.json` і їхній README з правилами малювання.
- `assets/illustrations/` — 22 ілюстрації гіда у форматі WebP (як у застосунку). `assets/illustrations_png/` — ті самі ілюстрації в PNG.
- `assets/app_icon/` — іконка застосунку для всіх щільностей Android і іконка сповіщень.
- `tokens.json` — кольори теми (`AppColors` у HEX), палітри вулика, мітки матки й категорій фінансів, розміри шрифтів і радіуси за частотою використання, список Material Icons з коду.

Примітки:
- `11_landscape/*` — на знімках видно бульбашку Telegram. Це оверлей телефона, а не частина застосунку.
- `02_qr/61b_qr_stickers_lowres.jpg` — зменшена копія. Наліпки відкриваються лише при генерації нових кодів.
- Екрана входу немає: обліковий запис уже був підключений, а виходити з нього я не став.
- Частина інтерфейсу малюється кодом, а не картинками: вулик-поштомат (`lib/ui/hive_postbox.dart`), сітка карти, кругова діаграма фінансів.
